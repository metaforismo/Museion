This branch is the whole v2 pass on Museion's surface: one linear history — 69 commits of product work plus this PR package, prepared during the hackathon judging freeze (nothing was pushed before 2026-08-12) and presented here as its three blocks — **visual unification** (one design system), **Museion Energy** (pressable depth and the course trail), and the **lesson canvas** (press grammar inside the checked canvas, the completion loop, the board).

The thesis running through all three: adopt the craft of Duolingo-class products — tactility, full-saturation moments, a path you stand on, a character that reacts — **without the manipulation**. No streaks, no XP, no leagues, no badges, no invented numbers, no guilt copy. Every number on screen is a real engine observation; every celebration is engine-verified; urgency may only reflect the real review queue. The energy pass exists to make honesty feel good instead of feeling beige.

All screenshots below are the real product driven through the real UI (lessons completed by answering the authored steps, misconceptions registered by answering wrongly), captured against a production build and annotated by `scripts/annotate-screenshots.mjs`.

Key decisions:

- **One face, one scale.** Fraunces is retired entirely; Inter carries display and body. The five-step type scale (`11/12/13/15/17px` + display steps) is enforced by a **shrinking ratchet test** — the allowlists of off-scale files may only get smaller, and they did (19 → 10 → the canvas files delisted in Block 3). Form fields sit at 17px because iOS zooms a focused field under 16px.
- **Machine-checked colour.** Every subject has an accent + tint pair; every accent clears 4.5:1 on its own tint, pinned by `tests/design-palette.test.ts` and a computed-contrast browser scan (canvas-composited, wash-aware) across 9 routes × 2 widths — zero failures.
- **Shared primitives.** `Card`, `Chip`, `Pressable`, `ProgressRail`, `SectionHeader`, `StatTile` under `src/components/ui/`; dashboard, library, review, evidence, Source Studio and settings are re-laid on them, so the same object never has two quieter twins.
- **Zone washes** give learn/create/account distinct grounds; Maia appears from state, never as furniture.

Key decisions:

- **Edge presses, blur floats.** The hard bottom edge (4px, same-hue `deep` shade at accent × 0.72, shipped as literals in the palette — components never compute colour) is the system-wide signature for "you can press this"; the blur ladder remains reserved for resting elevation. Press physics live once in `globals.css`, behind the global reduced-motion switch.
- **One full-fill element per view.** Tints stay the resting language; the page's primary action and the trail's current node take the full accent.
- **The trail is honest ground.** Done / current / ahead derive from the real record; ahead nodes are never padlocked because Museion recommends order, it does not lock content. **No per-lesson transfer flags:** that evidence is not derivable per-lesson for authored courses, so per the honesty boundary the path ships without them rather than faking them.
- **Juice with real numbers only.** Count-ups approach the record from below and land on it exactly (instant under reduced motion); the review press carries the actual queue count in gold with ink text (white-on-gold fails contrast at 2.80:1 — the pair is baked into the variant so no caller can re-decide it).

## Block 3 — The lesson canvas

Spec: [`docs/superpowers/specs/2026-07-25-lesson-canvas-energy-design.md`](https://github.com/metaforismo/Museion/blob/v2/sites/docs/superpowers/specs/2026-07-25-lesson-canvas-energy-design.md)

Key decisions:

- **Correct-green is reserved for engine-checked outcomes.** The checked-correct surface blooms full green; every decorative green in the canvas was removed (Maia's idle status dots, the recursion lab's window chrome, a trace line that was green regardless of correctness).
- **The key stays down while the engine decides** (`pressable-held`), and checked-wrong deflates the key through the shake beat — driven by a timer, not `animationend`, because reduced-motion suppresses the animation and an event-driven release would stick the key down forever.
- **Completion leads with the observation** — the exact session counts (`first-try/steps`, attempts, hints), then the word-for-word caveat that completion is not mastery. Zero copy changes.
- **The primary press returns to the trail, and the old "continue to next lesson" shortcut was removed** — the loop's payoff is watching the ground move: the course page validates `?completed=` **server-side against the real record** (a hand-typed URL for an uncompleted lesson animates nothing), plays the node fill and rail draw once, then strips the param. The next lesson is one press away at the node the animation just drew the eye toward.
- **The board:** 64px current / 52px other nodes, 8–9px rail, done/ahead rows title-only, and exactly one tab stop per lesson row (the circle went presentational; the press carries `aria-current` and the sr-only position).
- **The locked transfer stays stripped** — walked end-to-end and screenshotted during review: no Maia, no press grammar, no celebration during the attempt.

## Known-open items (this PR does not fix them)

- **`build/sites-vite-plugin` — resolved.** `vite.config.ts` imported a plugin that was never committed (`/build` is gitignored) and whose contents were lost, so it could not be recovered. Nothing depended on it — security headers live in `worker/index.ts`, the OG image is a static asset, D1/R2 bindings come from `cloudflare()`, and Codex stubbing is inline in the same config. Verified by building with a no-op stand-in and with the import removed: identical 146-file `dist`. The dangling import is gone, `verify:sites` passes, `next build` succeeds, and typecheck is now at **0 errors** — that lone error was this import.
- **Multiple-choice wrong answers never register their authored misconceptions** (pre-existing, found while seeding these screenshots): the choice control submits the option *index*, the verifier accepts an index for correctness, but `matchMisconception` compares the submission against the authored option *text* — so the triggers can never match. Numeric/expression misconceptions work; this PR's seeded queues use numeric steps for that reason. (`src/components/LessonPlayer.tsx` `onSubmit(String(selected))` vs `src/lib/engine/verifier.ts` `matchMisconception`.)
- The `course-review-desktop` screenshot is stale: `/api/compiler/runs` requires a ChatGPT Sites account actor, so the flow cannot complete locally (same reason `verify:ui`'s Source Studio section times out outside the deployment).
- Algebra's sky tint matches the learn-zone wash; worked around with a 3px accent edge on the hero. A neutral learn wash is the real fix.
- The crest wash is invisible for the palest tints (CS violet, algebra sky); arithmetic's `#fff2ad` is louder than the other five as a full-page wash.
- Named-size allowlist survivors, by design: the Judge canvas (`JudgeExperience`, `JudgeDeferredPanels`) and `LandingCoursePreview`.
- Canvas minors deferred: the multiple-choice *option* selection is lapis on every subject (only Check was specced subject-accent), and "Take a hint" remains a quiet gold outline on purpose — hints should not be the loudest thing on the card.
